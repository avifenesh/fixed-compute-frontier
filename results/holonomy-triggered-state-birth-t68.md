# T68 holonomy-triggered state birth — cycle obstructions as representation alarms

Date: 2026-08-01  
Status: **ALGEBRAIC DIAGNOSTIC RETAINED AFTER AUDIT; INTELLIGENCE MECHANISM CLOSED; NO RUN**

## 0. Research question

T49 stated the right operation but assumed the hardest resource: find two
histories that the current representation aliases and then find an action word
that distinguishes them. T68 asks whether algebra can expose that failure more
directly:

> If locally learned action transformations cannot be made globally
> path-independent, can the resulting closed-loop obstruction force the model
> to create exactly the hidden state needed to explain its experience?

The proposed signal is **holonomy**: compose learned local transformations
around a loop that returns to the same represented observation. A nonidentity
composition proves that the edge transformations are not the differences of
one globally consistent coordinate assignment. It does **not**, by itself,
prove that the environment contains a missing latent variable; model error,
noise, and genuine curved geometry are competing explanations.

## 1. Exact finite setting

Let `Q=(V,E_geom)` be a finite connected graph, where `E_geom` counts
unoriented geometric edges. Every orientation `e=(u,v)` of such an edge has a
reversible label `g_e` in a group `G`, with

\[
g_{\bar e}=g_e^{-1}.
\]

The group acts on a fiber `F` on the left. For a path
`p=e_1...e_m`, traversed in that order, define

\[
g(p)=g_{e_m}\cdots g_{e_1}.
\]

Thus a fiber value evolves as `f -> g(p)f`. For a loop `ell` based at `r`,
`g(ell)` is its holonomy. Changing the local frame at vertices conjugates a
based loop holonomy; identity versus nonidentity and conjugacy-invariant
statistics are gauge invariant.

With this convention, path concatenation satisfies

\[
g(pq)=g(q)g(p),
\]

so based-loop transport is an anti-homomorphism. A vertex-frame change
`a_v in G` sends

\[
g_{u\to v}\longmapsto a_vg_{u\to v}a_u^{-1},
\]

and conjugates a loop based at `r` by `a_r`.

This setting assumes that actions admit reversible, reliably estimated,
group-valued local transports. Section 6 states why that is a narrow boundary,
not a model of general experience.

## 2. T68.1 — exact cycle obstruction theorem

There exist vertex labels `h_v in G` satisfying

\[
g_{u\to v}=h_v h_u^{-1}
\]

for every oriented edge if and only if every closed loop has identity
holonomy.

### Proof

If the edge labels have this form, the product around
`v_0 -> v_1 -> ... -> v_m=v_0` telescopes:

\[
(h_{v_0}h_{v_{m-1}}^{-1})\cdots
(h_{v_2}h_{v_1}^{-1})(h_{v_1}h_{v_0}^{-1})=I.
\]

Conversely, select a root `r` and a path `p_v` from `r` to each vertex. Set
`h_v=g(p_v)` and `h_r=I`. For edge `e=(u,v)`, the path consisting of `p_u`,
then `e`, then the reverse of `p_v` is a loop. Its identity holonomy gives

\[
h_v^{-1}g_e h_u=I,
\]

so `g_e=h_v h_u^{-1}`. QED.

Therefore nontrivial loop holonomy is an exact certificate that no single
global flat assignment explains all local transformations.

### Finite diagnostic basis

Choose a root and spanning tree. Every non-tree edge creates one rooted
fundamental loop: follow the root path to one endpoint, cross the chord, and
return to the root along the other tree path.
There are

\[
\beta=|E_{geom}|-|V|+1
\]

such loops. The fundamental group of a connected graph is freely generated by
them. Hence checking identity holonomy on these `beta` rooted loops is
sufficient for flatness, even for noncommutative `G`; checking all possible
loops is unnecessary. This counts algebraic constraints, not independent
statistical evidence or environment samples. Fundamental loops share tree-edge
estimates, and different bases can have very different noise conditioning.

## 3. T68.2 — the canonical fiber lift

Define the lifted state space

\[
\widetilde V=V\times F
\]

and lift an edge `e=(u,v)` to

\[
(u,f)\longmapsto(v,g_e f).
\]

This is a first-order Markov transition on the enlarged state. A visible loop
can return to `v` while moving the fiber by its holonomy, so histories that
were collapsed at the visible node become distinct lifted states.

Let `K_r={g(ell): ell is a loop based at r}` be the holonomy subgroup. Starting
from `(r,f_0)`, returns to visible node `r` reach exactly the orbit

\[
K_r f_0=\{kf_0:k\in K_r\}.
\]

If `F` is finite, the lift uses at most `|V||F|` states. If the action has a
small finite orbit, arbitrary path history is compressed into one orbit
element rather than stored verbatim. If the orbit is infinite or grows with
experience, no bounded-memory claim survives.

More precisely, the orbit is the coset set

\[
K_r/\operatorname{Stab}_{K_r}(f_0),
\]

which need not be a quotient group. From one start, the reachable lifted
component has `|V||K_r f_0|` states when every visible vertex is reachable.
A nonidentity group element in the action kernel, or in the stabilizer of
`f_0`, creates no new represented state. The semantically relevant obstruction
is therefore the induced action on a behaviorally distinguishable orbit, not
raw nonidentity holonomy alone.

This construction is a classical derived/voltage-graph style lift. The new
research question is not whether the lift exists; it is whether a learner can
use reliable loop obstructions to birth the correct factor from raw experience
more effectively than existing latent-state learners.

## 4. T68.3 — conditional minimum state requirement

The orbit size is not automatically a lower bound on predictive memory. Some
fiber values may have identical futures. Add the necessary behavioral
condition:

Assume the orbit is finite. For every distinct `f,f' in K_r f_0`, suppose
there exists one common legal intervention/test for that pair whose outcome
distribution differs when started from `(r,f)` versus `(r,f')`. Then the
histories reaching those fibers occupy at least

\[
|K_r f_0|
\]

distinct causal-state/Myhill--Nerode equivalence classes. Any deterministic
exact sufficient statistic of history that losslessly labels those finite
classes therefore needs at least

\[
\lceil\log_2 |K_r f_0|\rceil
\]

bits in a fixed binary encoding.

### Proof

If a deterministic sufficient statistic assigned two orbit elements to one
predictive state, its
future distribution under every continuation would have to be identical from
both. This contradicts the behavioral condition. The cardinality and bit
bounds follow by the pigeonhole principle. QED.

Holonomy supplies candidate distinctions; future behavior determines whether
they are semantically necessary. Without the behavioral condition, internal
geometric twist can be irrelevant to prediction and should not trigger state
growth.

This is not a lower bound on nominal HMM state count, PSR/OOM linear dimension,
or neural width: a low-dimensional real-valued belief or predictive vector can
take many values. For an infinite pairwise-distinguishable orbit, the valid
conclusion is only that no finite discrete exact statistic suffices.

## 5. What the mechanism would be

An admitted learner would require this loop:

```text
learn local action transports
    -> maintain a spanning tree and chord loops
    -> estimate gauge-invariant loop residuals on fresh executions
    -> distinguish map error from persistent path-dependent state
    -> instantiate the smallest supported fiber/orbit
    -> demand novel out-of-loop predictions
    -> retain, merge, or roll back the new state factor
```

The crucial step is not computing a matrix product. It is model selection among
at least three explanations:

1. local transport estimation error;
2. observation aliasing or an omitted dynamical state; and
3. real path-dependent/curved dynamics already representable without the
   proposed discrete fiber.

A valid state birth must predict new continuations better than refitting the
old transport maps, on private trajectories not used to detect the loop.

## 6. Noise and noninvertibility boundary

For estimated matrix transports, a nonzero product is expected under finite
data. The exact theorem cannot be used as a statistical test without a noise
model. At minimum, compare two nested hypotheses on fresh loops:

\[
H_0:\quad \widehat g_e\sim
\text{a declared edge-estimation law centered on }h_vh_u^{-1},
\]

\[
H_1:\quad \text{a shared latent fiber predicts residual loop effects}.
\]

Charge data used to select loops, fit transports, choose the fiber, and test
out-of-loop predictions separately. Reusing the detection loops for validation
creates a guaranteed selection bias.

For matrix groups, an implementable null must specify a group-respecting error
coordinate or embedding, edge-estimation covariance, correlations induced by
shared tree edges, basis selection, and multiple-testing correction. Additive
ambient noise generally leaves the group and is not a valid default model.

General controlled dynamics are often stochastic and noninvertible. A group
label then does not exist. One can move to linear operators, stochastic
kernels, groupoids, or semigroups, but:

- reverse edges need not be available;
- a loop product may lose information rather than expose a reversible twist;
- approximate operator factorization is model-class dependent; and
- a generic predictive-state model already represents action-conditioned
  history without this geometric restriction.

No theorem in T68 extends automatically across that boundary.

## 7. Direct prior-art collision

The mathematical ingredients are substantially occupied:

- [Gauge-invariant representation holonomy](https://arxiv.org/abs/2601.21653)
  already estimates pathwise loop transport as a gauge-invariant learned-
  representation diagnostic and studies robustness and representation-geometry
  correlations. Its image-sampling aliasing control is not POMDP state aliasing,
  so it occupies the diagnostic rather than online state birth.
- [Holonomy Grid Codes for Generalisation Under Directed Actions](https://openreview.net/forum?id=RJBvW7ZdhG)
  gives twisted action representations, exact spectral structure, transfer
  principles, and a dimension lower bound induced by nonzero holonomy.
- [Clone-structured graph representations](https://www.nature.com/articles/s41467-021-22559-5)
  already allocate hidden clones to disambiguate identical observations by
  sequential context and support planning.
- [Differentiable CSCGs](https://arxiv.org/abs/2607.12382) couple that mechanism
  to a learned visual code and recover aliased graph structure end to end.
- Predictive-state methods directly represent action-conditioned future tests;
  [PSIM](https://proceedings.mlr.press/v48/sun16.html) learns the recursive
  predictive-state filter, while
  [RPSP](https://proceedings.mlr.press/v80/hefny18a.html) integrates one with a
  learned policy.
- Classical HMM state discovery already performs data-driven splitting; for
  example, [Fast State Discovery for HMM Model Selection and Learning](https://proceedings.mlr.press/v2/siddiqi07a.html)
  proposes a top-down state-splitting algorithm.

The exact unoccupied-looking seam is narrower: use a compact independent cycle
basis not merely to diagnose a representation, but to propose a shared
algebraic fiber; validate it by novel intervention-conditioned predictions;
and grow or retract that factor online. That is currently a synthesis
hypothesis, not a demonstrated new intelligence principle.

## 8. Strongest controls and a possible gain

The candidate must beat, at matched trajectories, stored state, and update
compute:

- differentiable and classical CSCG with clone count selected by validation;
- an HMM/POMDP state-splitting learner;
- PSR/OOM/spectral predictive-state learning;
- a recurrent world model with equivalent hidden-state width;
- a transformer with full trajectory access; and
- the same model with generic change-point, cycle-consistency, and residual
  losses.

The only plausible large gain is **structured acquisition**: if many visible
contexts share the same small path-dependent transformation group, one learned
fiber action could explain and transfer distinctions across all of them. A
generic clone graph can represent the same solution but may need to relearn
separate transitions. However, a factorized CSCG or equivariant latent model is
an exact conditional control and may absorb this advantage.

An experiment is admissible only after a theorem or pre-run argument identifies
a family where:

1. the shared fiber is identifiable from available interventions;
2. the number of required loop executions is asymptotically or substantially
   smaller than the strongest structured control's learning bill;
3. novel-path prediction or planning improves substantially, not just the
   holonomy diagnostic; and
4. the gain survives raw observations, noise, model-selection cost, and held-
   out topologies.

No such acquisition theorem has been established here.

## 9. Fatal controls

Close the mechanism without a run if any of these holds:

1. learned holonomy changes when the estimator, chart, or loop discretization
   changes within its uncertainty range;
2. refitting local transports removes the residual on fresh loops;
3. fiber states do not predict behavior outside the loops that created them;
4. CSCG/PSR discovers an equal or smaller sufficient state with no more data;
5. the candidate preallocates enough fiber capacity that "state birth" is only
   ordinary latent activation;
6. a structured control receives the same group factorization and ties;
7. noninvertible or stochastic dynamics require replacing the whole theorem by
   a generic operator model; or
8. the positive result is confined to toroidal/grid navigation.

## 10. Final disposition after independent audit

T68 proves a clean obstruction theorem, a finite cycle basis, a canonical
hidden-state lift, and a conditional state lower bound. Those are useful tools
for deciding when a representation cannot remain flat.

It does **not** show how to learn better than CSCG, PSR, HMM state splitting, or
a structured recurrent world model. A matched control supplied the same group
factorization shares exactly the proposed fiber update and can learn from open
paths before T68 closes a loop. The independent audit therefore closes T68 as
an intelligence mechanism and retains it only as a narrowed algebraic
diagnostic. No local or GPU experiment is justified.
