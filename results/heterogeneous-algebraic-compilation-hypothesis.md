# Heterogeneous algebraic compilation — hypothesis

Status: T0 derivation; not a breakthrough claim  
Date: 2026-07-30

## Key shift

Backpropagation is a general-purpose continuous optimizer.  Some subsequences
of an LM corpus are generated by structure with a cheaper native algebra:
finite-state transitions, permutations, sparse parity, modular relations, or
linear recurrences over a finite field.  The hypothesis is to solve such a
component with its native specialist algorithm during training, then compile
the solution into weights of the unchanged dense model.  The specialist and
its state are deleted at export.

This is not a claim that a compiler is a stronger general model.  It is a
claim that a narrow exact solver can recover one identifiable structure much
more cheaply than a universal gradient trajectory, while the deployed model
is already expressive enough to execute the recovered circuit.

## Exact SwiGLU multiplication lemma

For `silu(z) = z sigmoid(z)`, sigmoid symmetry gives

```text
silu(z) - silu(-z) = z.
```

Therefore two ordinary SwiGLU channels exactly multiply arbitrary linear
features `u^T h` and `v^T h`:

```text
[silu(u^T h) - silu(-u^T h)] (v^T h)
    = (u^T h)(v^T h).
```

Opposite rows in the gate projection, duplicated rows in the up projection,
and opposite columns in the down projection implement the identity with the
ordinary inference graph.  A binary tree of residual SwiGLU blocks can compile
a degree-`k` product/parity with `2(k-1)` intermediate channels and
`ceil(log2(k))` layers.  There is no added inference parameter, state, branch,
or operator after compilation.

## T0 separation theorem target

Let observations obey an unknown linear recurrence over `GF(2)`:

```text
b_t = dot_GF2(s, [b_(t-d), ..., b_(t-1)]),
```

where `s` is an unknown sparse or dense binary mask.  Once the context matrix
has rank `d`, Gaussian elimination recovers `s` exactly in `O(d^3)` bit
operations and `O(d)` labeled windows.  Encoding bits as signs turns the same
rule into a product of selected signs, which the lemma compiles into a fixed
SwiGLU circuit.

The intended qualitative separation is not based on infinitesimal step size:
the candidate changes the algebra of identification from real-valued local
descent to finite-field equation solving.  An inconsistent system must cause
abstention, providing a random-label control.

## What would count

The T1 gate must use the exact same random model initialization and architecture
in every arm.  Compilation may begin only after a charged prefix.  It advances
only if:

1. the compiler reaches at least `99%` held-out recurrence accuracy;
2. tuned AdamW and matrix-normalized controls remain below `60%` at matched
   compute and below `80%` at `2x` charged compute;
3. three seeds and unseen coordinate permutations pass;
4. an ordinary linear/Markov protected slice is noninferior;
5. inconsistent random labels make the solver abstain and remain at chance;
6. solver, compilation, and verification work is fully charged.

A pass would establish an existence proof for heterogeneous training algebra,
not a general-LM breakthrough.  Advancement would require automatic structure
detection on a natural token stream and a protected 37M-class LM screen.

## Known boundary

The components are not individually novel.  Tensor/moment initialization,
analytical neural solutions, and compiled neural modules exist.  Relevant
collisions include:

- Tian, *Composing Global Solutions to Reasoning Tasks via Algebraic Objects
  in Neural Nets*: <https://openreview.net/forum?id=tD7MLq0dbZ>
- Weng et al., *Mastering Symbolic Operations: Augmenting Language Models with
  Compiled Neural Networks*: <https://openreview.net/forum?id=tpIUgkq0xa>
- Abbe et al., *Learning High-Degree Parities: The Crucial Role of Weight
  Initialization*: <https://arxiv.org/abs/2412.04910>

The research contribution would have to be the automatic, charged,
fixed-architecture transition from discovered corpus structure to protected
weights—not the fact that algebraic rules can be solved or hand-compiled.
