# Reversible slot-grammar plane T33 — paper gate

Status: **PAPER CANDIDATE; NO CODE, DATA CENSUS, MODEL, OR GPU RESULT YET**  
Date: 2026-07-31

## P0. End claim

At identical complete serving bytes, KV state, request tokens, active work, and
H100/H200 latency, a from-zero model plus a charged offline compiler should
retain more one-shot factual knowledge and answer title-disjoint natural
comparison questions substantially better than the strongest dense,
self-indexed, summary-memory, and conditional-memory controls.

The proposed different object is not another document vector.  It is:

```text
lossless raw-token base
    + reversible one-hole grammar rules
    + typed (document, rule, raw-span) edges
    + one shared query-to-rule reader
```

The different currency is corpus-wide offline comparison and grammar-building
work.  Every persistent byte and every serving operation remains charged.

The final gate remains at least 80% frozen natural accuracy, at least ten
absolute points above the best matched control, at least a 15-point
correct-minus-shuffled causal gap, protected NLL within 0.5%, and noninferior
complete serving latency on every frozen point.

## P1. Named obstruction

The preceding candidates fail on opposite sides of the same boundary:

- a free learned record has per-document gauge freedom and memorizes exposed
  reads without defining unseen ones;
- exact token storage preserves every fact but supplies no small semantic
  address;
- a three-view tensor can identify relations only after relation-bearing
  events and views have already been selected;
- exact positive co-incidence cannot select events when most facts occur once;
- raw cloze training does not prove that its relevance relation matches future
  natural questions.

T33 asks whether repeated *surface programs* can identify event boundaries
without first identifying semantic relation labels.  A relation rule is an
observable string context with one variable hole.  It is retained only when
multiple raw sentences independently instantiate the same context and the
factorization saves a fully disclosed two-part code.

This can organize a one-shot fact: the rule must recur, but a particular
`(document,value)` binding need occur only once.

## P2. Typed operator graph

Let the raw corpus be titled token records.  The compiler sees exactly
`document_id`, `title`, and `text`.

```text
segment(raw text) -> ordered raw sentence spans
normalize(exact own-title surfaces) -> reversible SELF-marked strings
anti_unify(sentence pairs) -> one-hole rule proposals
verify(rule, corpus) -> exact raw occurrences and fill spans
select(proposals) -> unambiguous positive-saving rules
write(rule occurrences) -> typed document edges
pack(raw records, rule dictionary, edges) -> persistent plane

route(raw question, title dictionary) -> small document candidate set
map(query state, rule dictionary) -> rule code
read(document handles, rule code, edges, raw base) -> exact raw value spans
reason(question state, value spans) -> ordinary answer logits
```

`normalize` replaces exact occurrences of the document's own title by one
typed `SELF` marker.  It records the replaced raw spans and never resolves
aliases or pronouns.  The document container remains a separate typed address;
it is not prepended to the sentence and is not asserted to be the grammatical
subject.  Denormalization must reconstruct the original bytes exactly.

Every compiled edge has the literal meaning:

```text
expanding rule[rule_id] with raw_base[document][start:end]
reconstructs the witnessed source sentence exactly.
```

The rule ID has no human semantic name.  A global permutation of IDs changes
nothing because writer and reader share it.

## P3. Restricted family and constructive recovery theorem

### Family

Let `Sigma` be a finite token alphabet.  A latent relation surface program is
a pair of fixed token strings

\[
\tau_r=(a_r,b_r),
\]

which generates sentence instances

\[
x_{r,e}=a_r\;v_{r,e}\;b_r.
\]

The document identity `e` is supplied by the raw title/container, not encoded
inside the rule.  The middle `v_{r,e}` is a nonempty bounded token span.  It
may occur only once in the entire corpus.

Assume:

1. **recurrence:** every retained `r` has at least two instances;
2. **boundary diversity:** for every `r`, some two instances have middle
   strings whose longest common prefix and suffix are both empty;
3. **separation:** no instance generated by `r` matches `(a_s, hole, b_s)` for
   `s != r` within the allowed hole bounds;
4. **single event:** each admitted sentence matches exactly one retained rule;
5. **positive code gain:** storing the rule once, one reference per instance,
   and all middle strings is shorter than storing the instance sentences
   literally under the frozen code;
6. **proposal isolation:** every pair-derived proposal with positive code gain
   that matches an instance of a retained relation is exactly one of the true
   `tau_r` rules.

Proposal isolation excludes a broad accidental hole that groups several true
rules or a narrow accidental hole that factors a repeated fragment inside the
values.  Without it the stated algorithm can reject a true rule because of a
spurious conflict; the first version of this paper omitted this necessary
condition.

These assumptions are deliberately stronger than natural language.  They name
the exact quantities the raw census must measure rather than transferring a
synthetic theorem by analogy.

### Algorithm

For every pair of distinct sentence strings:

1. compute the full common-prefix and common-suffix lengths;
2. among prefix/suffix lengths bounded by those values, choose the pair with
   maximum total anchor length that leaves a nonempty at-most-127-token middle
   in both strings and keeps each anchor at most 127 tokens; break a tie by the
   longer prefix and then lexical serialization;
3. propose the resulting `(a,b)` when such a pair exists;
4. scan the raw corpus for every exact `a + middle + b` match;
5. retain only proposals with at least two distinct documents, positive code
   gain, and no sentence that matches another retained positive-gain rule;
6. assign rule IDs by the lexical serialization of `(a,b)`.

No embedding, parser, model, answer, support span, or latent label appears.

### Theorem 1: exact recovery on the restricted family

Under assumptions 1--6, the algorithm recovers every `tau_r`, every admitted
middle span, and the relation partition up to a global permutation of rule
IDs.

### Proof

By boundary diversity, one pair of instances for `r` has no common middle
prefix or suffix.  Their full common prefix is therefore exactly `a_r` and
their full common suffix is exactly `b_r`.  That pair is feasible, jointly
maximizes total shared boundary, and the algorithm proposes `tau_r`.

Every instance of `r` matches that proposal by construction.  Separation
prevents an instance of another relation from matching it.  Proposal isolation
rules out an eligible spurious proposal on the same instances; the single-event
condition therefore prevents conflicts, and positive code gain retains the
proposal.  Thus its exact match set is the complete set of instances of `r`.
Lexical numbering may rename the recovered relations but cannot alter the
partition or any fill span.  Substituting each recorded middle back between
its two literal anchors reconstructs the source sentence exactly.  QED.

### Theorem 2: one-shot fact retention

Once `tau_r` is recovered from any two boundary-diverse training instances, a
new sentence `a_r v b_r` assigns the previously unseen `v` to rule `r` by an
exact string test.  No repeated `(entity,value)` tuple or learned document
coordinate is required.

This is the precise separation from T28's positive co-incidence quotient.

## P4. Two-part code and selection rule

Let `B=ceil(log2(|Sigma|+1))`.  For one candidate rule with `m` instances,
anchor length `A=|a|+|b|`, and middle lengths `F_i`, literal storage costs

\[
C_{literal}=B\left(mA+\sum_iF_i\right).
\]

Let `H` be the exact self-delimiting metadata cost for anchor lengths,
occurrence count, and integrity fields, and let `R` be the bits needed for one
rule reference in the frozen dictionary.  Factored storage costs

\[
C_{rule}=BA+H+mR+B\sum_iF_i.
\]

The exact gross saving is

\[
G=B(m-1)A-H-mR.
\]

The rule is eligible only when `G>0`; all bit fields and `H,R` are fixed before
the natural census.  No downstream score can promote a zero-saving rule.

Natural proposals can overlap even though the theorem family cannot.  T33
does not solve an opaque global grammar optimization problem.  It rejects
every sentence participating in more than one eligible rule.  This conservative
rule makes selection deterministic and locally explainable.  It may destroy
coverage; that is an intentional kill surface.

The smallest unrestricted grammar problem is NP-hard.  T33 makes no claim of
finding a minimum grammar.  Ordinary grammar compression and grammar
self-indexing remain mandatory controls.

## P5. Failure theorems and declared non-domain

### Theorem 3: singleton impossibility

Given one raw sentence `x`, every split `x=a v b` is observationally compatible
with a different one-hole rule.  Without another occurrence or an external
assumption, raw strings alone cannot identify the intended boundary.

### Theorem 4: anchor collision impossibility

If instances of two semantic relations generate the same observable anchor
pair and overlapping middle language, their rule assignments are not
identifiable from this object.  Any raw-only compiler must emit the same
observable rule state in a world where they are one relation and a world where
they are two.  T33 therefore merges the surface program and makes no semantic
purity claim.  A planted-world evaluator marks the latent distinction
unrecoverable; the later natural information oracle must kill a merge that is
not task-sufficient.

### Other exact failure surfaces

- common prefixes/suffixes inside every value can make slot boundaries
  non-identifiable;
- a sentence expressing multiple facts violates the single-event family;
- pronouns and implicit document subjects may not expose the required anchors;
- paraphrases remain different rule IDs unless raw recurrence connects them;
- negation or scope can be swallowed by the hole if anchors are inadequate;
- question language may be disconnected from declarative rule language;
- a relation can be structurally valid but useless for the frozen task;
- grammar state can consume more bytes than it saves;
- branchy rule lookup can lose physically despite lower arithmetic.

The compiler must abstain at ambiguity.  Confidence without an observable
witness is a rejection, not partial credit.

## P6. The one empirical link

The recovery theorem identifies raw surface programs, not their natural
question paraphrases.  The sole intended learned composition hypothesis is:

> from the same from-zero raw-language training, a fixed-size query mapper can
> map an unseen natural question to the recovered declarative rule ID.

Raw-derived masked-slot examples may train this mapper only after the grammar
and natural-information gates pass.  Every control receives the same examples,
targets, training tokens, and optimizer opportunity.  The standalone-cloze
paper closure remains binding: success on the raw proxy is not evidence of
natural transfer, and natural query mapping must be tested once, frozen, with
zero/shuffle/wrong-rule controls.

Alias and implicit-document routing are separate.  The first witness retains
literal title candidate generation and must solve selection among all literal
candidates rather than assuming the correct two handles.

## P7. Persistent-state construction

The lossless direct `uint16` token plane remains authoritative.  A rule edge
does not duplicate the value tokens; it points into that plane.

With at most 4,096 rules, 128-token records, and 24 admitted edges per
document, one edge uses exactly 32 logical bits:

| field | bits |
|---|---:|
| rule ID | 12 |
| value-span start | 7 |
| value-span length minus one | 7 |
| flags/integrity | 6 |
| total | **32** |

Twenty-four edges cost 96 bytes per document.  The rule dictionary stores its
literal anchor token IDs once.  Document edge counts, dictionary offsets,
checksums, and physical alignment are all charged.

The post-census physical ledger must include:

- exact `uint16` raw-base bytes and lengths;
- every rule token, offset, and edge byte;
- title/candidate-router state;
- query mapper and keyed-reader weights;
- workspace, graph pools, and alignment;
- the exact FFN or other state removed to fund them.

No sidecar may be described as free because the grammar compressed some text.
Only the complete net byte count matters.

A flat 4,096-way query classifier would itself require a large persistent
output table.  The mapper must therefore disclose whether it emits twelve
bits, compares against a charged low-rank rule dictionary, or uses another
typed construction.  Arbitrary binary IDs may be difficult to generalize to;
that difficulty belongs to B6 and may not be hidden by an uncounted rule
embedding table.

## P8. Constructive keyed reader

Given one 12-bit rule code and up to 24 edges in a document, exact nibble
equality can identify the matching edge with the retained paired-SiLU bipolar
product identity.  The selected `(start,length)` then gathers the original
token IDs and the model's already-resident shared embeddings.

This gives an exact local contract:

```text
correct rule code + unique edge -> exact raw value-token sequence
```

It does not construct the natural query code.  Duplicate rule edges may return
a bounded set only if the final interface and byte/work ledger price that set;
otherwise the document is rejected for that rule.

The reference reader must be compared with a direct scan, binary search over
sorted rule IDs, a compressed self-index locate/extract, and a matched learned
conditional lookup.  The cheapest legal implementation becomes the control.

## P9. Breakthrough-size derivation

Let:

- `c_route` be probability that the two correct documents are in the raw-only
  candidate set and selected;
- `c_struct` be per-document probability that an answer-sufficient value span
  has a unique admitted rule edge;
- `c_map` be probability that the natural question maps to that rule;
- `c_read` be exact keyed-read success;
- `c_reason` be answer success given both exact value spans.

An optimistic two-record ceiling is

\[
A_{candidate}\le
\min\left(1,
A_{shortcut}+(1-A_{shortcut})
c_{route}\,c_{map}\,(c_{struct}c_{read})^2c_{reason}
\right),
\]

where `A_shortcut` is measured by destroying the plane, not assumed.

If the plane path itself is required to support both records on at least 80%
of rows, then it requires

\[
c_{struct}\ge\sqrt{0.8}=0.8944.
\]

The frozen natural structure audit adopts this conservative 89.44%
per-document support-span gate before a mapper or model is trained.  It is a
design requirement ensuring that structure alone can support an 80% two-read
path, not a mathematical necessity for 80% final accuracy when
`A_shortcut > 0`.

For comparison, granting the current shortcut accuracy `A_shortcut=0.567308`
and assuming the path repairs only shortcut errors, an overall 80% ceiling
requires the complete plane path to succeed on at least

\[
\frac{0.8-0.567308}{1-0.567308}=0.5378
\]

of shortcut failures.  The stricter structural gate prevents a weak sidecar
from passing only because the ordinary model already answers many rows.

Relative to the current 56.7308% dense reference and 89.4231% explicit-record
ceiling, reaching 80% also requires realizing at least 71.18% of the available
oracle gap before protected-quality loss.  A low-coverage grammar or a small
NLL gain cannot promote.

## P10. Strongest controls

All controls receive the same raw corpus, derived masked-slot examples,
compiler time accounting, title candidate set, total resident bytes, and
complete serving envelope where applicable.

1. width-1,024 dense from-zero model;
2. byte-matched reduced-width model with free learned state;
3. direct `uint16` raw plane with the best matched bounded scanner;
4. compressed full-text self-index/grammar self-index plus the same mapper;
5. equal-byte learned document summaries;
6. equal-byte Engram-like conditional learned memory;
7. exact recurring surface templates without slot factoring;
8. lexical/IDF and fixed-window span pointers;
9. candidate with rule IDs shuffled globally, edges shuffled between
   documents, span pointers randomized, or the raw base replaced;
10. candidate with correct rules but the query mapper zeroed or permuted.

A globally permuted rule dictionary is an invariant, not a destructive
control: permuting dictionary IDs and every matching edge must leave results
unchanged.

A grammar self-index given the same recovered rule dictionary can reproduce
the candidate's logical lookup by locating `a + hole + b` and extracting the
hole.  Therefore T33 does not claim a function-class advantage over the
strongest self-index.  Materialized typed edges buy only a different
byte/latency point: more persistent pointers in exchange for bounded lookup.
If the self-index matches or beats that complete point, the materialized plane
is absorbed and withdrawn.

Grammar compression, self-indexing, anti-unification, and unsupervised relation
extraction are prior art.  T33 claims novelty only if the complete conjunction
survives: raw-only reversible slot discovery, one-shot typed bindings, exact
in-checkpoint reads, a substantial natural reasoning gain over all controls,
and unchanged complete serving cost.

## P11. Explainable block cards and microbench order

### B0 — sentence/span observer

- **Type:** raw UTF-8 titled document -> ordered byte/token sentence spans.
- **Meaning:** exact substrings only.
- **Invariant:** concatenation plus recorded separators reconstructs the raw
  input.
- **Microbench:** exhaustive punctuation/Unicode/title cases and reverse-order
  corpus construction.
- **Kill:** one irreproducible span or evaluator-visible field.

### B1 — pair anti-unifier

- **Type:** two token sequences -> `(prefix,middle_1,middle_2,suffix)`.
- **Meaning:** exact maximum-total nonoverlapping shared boundary with a
  nonempty hole in both inputs.
- **Invariant:** both inputs reconstruct exactly.
- **Microbench:** exhaustive alphabet size three, sequence length at most six,
  checked against an independent brute-force enumerator.
- **Adversaries:** equal strings, nested repeats, all-common prefixes, empty
  middles, overlap, order swap.
- **Kill:** one mismatch or asymmetric serialized rule.

### B2 — rule verifier/selector

- **Type:** proposals plus raw corpus -> unambiguous positive-saving rules and
  witnessed occurrences.
- **Meaning:** every occurrence is one exact substitution proof.
- **Invariant:** rule expansion reproduces the source; every rejected
  ambiguity is reported.
- **Microbench:** exhaustive small planted worlds satisfying and violating
  each theorem assumption; independent dense and indexed matchers.
- **Kill:** missed recovery in-family, a confident semantic-purity claim for
  an observationally merged world, or failure to reject an observable proposal
  conflict.

### B3 — natural structure census

- **Type:** frozen raw-only compiler -> rules, edges, bytes, and raw witnesses.
- **Meaning:** no semantic score enters construction.
- **Microbench:** first build with labels sealed; then reveal support spans only
  to measure coverage, impurity, ambiguity, and answer-span containment.
- **Kill:** `c_struct < 0.8944`, more than 24 required edges per addressed
  document, dictionary/edge byte overflow, or order/entity-shuffle leakage.

### B4 — keyed digital read

- **Type:** one rule code plus one document edge array -> exact raw span.
- **Invariant:** exhaustive 12-bit/position boundary checks on small worlds;
  exact reference agreement on frozen natural state.
- **Controls:** missing, duplicate, random, shuffled, nearest-wrong code.
- **Kill:** collision, silent duplicate, numerical margin failure, or a
  cheaper legal control implementing the same read.

### B5 — decoded information oracle

- **Type:** question plus decoded rule/value witnesses -> answer.
- **Meaning:** representation ceiling only.
- **Kill:** below 80%, below +10 points over the strongest matched information
  control, or correct-minus-shuffled below 15 points.

### B6 — raw-only query mapper

- **Type:** question state plus frozen rule dictionary -> rule code.
- **Training:** raw-derived examples only; grammar frozen before natural
  support/answer access; at least three seeds.
- **Controls:** all P10 memory interfaces and shortcut destructions.
- **Kill:** failure on unseen templates/entities, template-only memorization,
  or insufficient natural mapping to support the final product bound.

### B7 — from-zero composition and physical graph

- **Type:** complete matched served models.
- **Gate:** final P0 thresholds on every seed and every serving point.
- **Non-claim:** a primitive kernel or one benchmark slice is not a smarter
  production model.

The order is strict: B0--B2 prove the local program; B3 tests whether the
natural bridge exists; B4--B5 test usefulness; B6 tests the sole learned link;
B7 alone tests the model claim.

## P12. Prior-art boundary checked before execution

- [Universal Schema](https://aclanthology.org/N13-1008/) establishes
  entity-pair by textual-pattern relation matrices.
- [Revisiting Unsupervised Relation Extraction](https://arxiv.org/abs/2005.00087)
  shows the importance of entity-type inductive bias and the difficulty of
  obtaining semantic clusters from unsupervised objectives.
- [Actively Supervised Clustering for OpenRE](https://aclanthology.org/2023.acl-long.273/)
  explicitly reports that unsupervised clusters struggle to align with
  relational semantics; T33 may not assume otherwise.
- [Self-indexed grammar compression](https://doi.org/10.3233/FI-2011-565)
  already provides compressed extraction and search over straight-line
  grammars; it is a control, not novelty.
- [Grammar Compression: Grammatical Inference by Compression](https://proceedings.mlr.press/v34/sakamoto14a.html)
  records both the grammatical-inference motivation and the NP-hardness of the
  minimum grammar problem.

T33's exact theorem concerns a restricted one-hole family.  It does not claim
general semantic parsing, minimum grammar discovery, paraphrase understanding,
or open-domain relation extraction.

## Paper decision

T33 is admitted only to an adversarial review of this paper.  If the theorem,
effect path, or strongest-control separation survives, the next executable
artifact is a frozen B0--B3 CPU preregistration—not a compiler implementation,
model download, or H100 run.
