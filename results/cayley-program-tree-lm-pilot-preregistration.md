# Cayley program tree — 10M-token language pilot preregistration

Status: **frozen before GPU model execution**  
Date: 2026-07-30

Pre-execution literature amendment: a pass must also face a matched BTT/Monarch
structured-matrix control.  This was added before any GPU execution of the
tree after reviewing the established structured-matrix compute frontier.

Pre-execution integrity amendment: the route-coordinate multiplier is
`1,103,515,247`, which is coprime to width 384.  The initially drafted common
LCG multiplier was divisible by three and would have restricted each depth to
one residue class.  It was rejected before any tree GPU execution; an
exhaustive frozen-width test now requires collision-free node coordinates at
every depth.

The same audit found that the drafted one-round affine matchings were three
disconnected 128-channel graphs at width 384.  They were also rejected before
GPU execution.  The frozen replacement is a reversible
quadratic-affine-quadratic permutation family whose three basis graphs are
3-regular and connected, with exact diameters 10 at width 384 and 16, 15, and
15 at width 4,096.  These topology formulas add integer/index arithmetic but
no checkpoint table.

## Primary edge

Edge B admission: match the full width-1,024 SwiGLU scratch model's language
quality with the same resident FFN parameter budget but only 8.203125% ideal
active FFN multiply-like work.

This pilot cannot establish faster inference.  A pass only authorizes stronger
conditional-memory controls and a fused hard-path kernel.

## Frozen model

Replace each of twelve SwiGLUs by the depth-nine Cayley program tree in
`experiments/cayley_program_tree.py`:

- 511 internal nodes and 512 possible paths;
- two edges per node, each holding gate/up/down diagonal `D`-vectors;
- three learned degree-three sparse Cayley bases cycled across depth;
- four Neumann terms in both basis directions;
- one fixed route coordinate and one learned threshold per node;
- route coordinates are generated by the collision-tested implicit integer
  hash and consume no checkpoint/index table bytes;
- sparse perfect matchings are generated by fixed reversible polynomial
  formulas;
  no permutation or inverse-index tensors are stored in the checkpoint;
- hard-forward/soft-backward binary route;
- down-payload initialization standard deviation `0.15`;
- route balance auxiliary coefficient `0.01`.

The Python reference materializes small formula-derived index vectors as
runtime workspace.  Their arithmetic, workspace, and gather behavior are
excluded from the ideal ledger and must be measured by the hardware gate.

At `D=384`, each candidate FFN has 1,179,583 learned scalars, 65 fewer than
SwiGLU's 1,179,648.  All attention, embeddings, normalization, residual
topology, tokenizer, and logits remain unchanged.

At BF16 the 65-scalar per-layer slack is 130 bytes.  One formula seed needs at
most eight host/config bytes per layer, so even charging that non-tensor
metadata leaves 122 bytes of checkpoint slack per layer.  Formula constants
are shared executable code, not per-layer tensors.

## Frozen protocol

Reuse the completed full-SwiGLU arm from the immediately preceding G7 run only
if its software, GPU, data hashes, seed, schedule, batch, token count, and 128
evaluation batches match exactly.

Candidate:

- seed 815;
- 305 optimizer steps, 30 warmup;
- sequence 512, microbatch 8, accumulation 8, global batch 64;
- AdamW `3e-4`, `(0.9,0.95)`, epsilon `1e-8`, weight decay `0.1`;
- gradient clip 1.0;
- 9,994,240 prediction tokens;
- the exact frozen train and validation hashes from the prior run;
- terminal evaluation on the same 128 batches of 32 sequences.

## Promotion gates

All must pass.

1. Integrity, data, environment, schedule, and finite-training gates pass.
2. Every candidate FFN has no more parameters than full SwiGLU; total model
   parameters do not exceed the baseline.
3. Candidate NLL is no more than 0.5% worse than full SwiGLU, and the paired
   upper 95% interval is within that noninferiority margin.
4. Candidate ideal active FFN ratio remains below 9% with every exclusion
   disclosed.  This is not a wall-clock claim.
5. On two validation sequences, median binary route perplexity is at least
   1.5, no depth has more than 90% of tokens on one bit globally, and at least
   25% of reachable nodes are visited at depths six through eight.
6. Forcing the all-zero path on the first 32 terminal evaluation batches
   worsens paired NLL by at least 0.5%, proving that stored path diversity is
   used.  Dynamic and forced evaluations must use identical examples.

A one-seed pass admits untouched seeds and these mandatory controls:

- an exact-byte 12-expert top-1 SwiGLU MoE: every expert has width 85,
  expert payload is `3 * 384 * 12 * 85 = 1,175,040` scalars, and its
  `384 * 12 = 4,608`-scalar router makes exactly 1,179,648 scalars.  Its
  router-plus-selected-expert ideal MAC ratio is 8.6914%, making it the direct
  mature conditional-compute control rather than a larger or slower MoE;
- equal-byte PEER/additive vector memory with matched active payload reads;
- equal-parameter and equal-compute BTT/Monarch structured projections;
- equal-byte hierarchical diagonal experts without Cayley basis changes;
- random/frozen routing and route-label permutation;
- longer training and protected capability slices;
- fused decode and prefill kernels with full byte, workspace, and latency
  accounting.

Failure closes this exact tree depth, payload, routing coordinate, basis count,
Neumann order, initialization, and schedule.  It is not tuned under the same
claim.
