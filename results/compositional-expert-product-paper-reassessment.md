# Compositional expert product: paper reassessment

Date: 2026-08-01  
Status: **VALID SCALING LAW, ALREADY KNOWN IN GENERAL FORM; NO RUN**

## Proposal and exact gain

Let a task route be a tuple

\[
z=(z_1,\ldots,z_m),\qquad z_i\in\{1,\ldots,K\},
\]

and let its transformation factor as

\[
f_z=A_{m,z_m}\circ\cdots\circ A_{1,z_1}.
\]

A flat expert table has `K^m` possible routes.  A compositional population
stores only `mK` primitive operators and activates `m`, yet can instantiate up
to `K^m` operator words.  If every primitive has description length `b`, the
nominal storage changes from `K^m b` to `mKb` while active work remains the
sum of the `m` selected primitive costs.

This gives a real combinatorial generalization property.  If training covers
every primitive in enough combinations, a new tuple can be executed without a
new flat expert.

## Exact boundary

The number of *routes* is exponential; learned information is not.  Every
composite lies in the semigroup generated by only `mK` operators.  An arbitrary
assignment of independent functions to all `K^m` tuples still requires
exponential information.

The strongest control is not a flat MoE.  It is any shared conditional program,
hypernetwork, tensor-factorized expert, or dense model that also implements the
same factorization.  Against that class, there is no current function or
resource separation.  The remaining claim is whether next-token training
discovers the correct factors and routes more reliably in the explicit
parameterization.

The natural-language bridge is also not free.  The model must infer which
independent attributes generate a transformation—such as domain, operation,
format, and style—from raw tokens.  If the factors are correlated or the order
is context-dependent, the `mK` construction no longer represents all required
composites.

## Prior-art collision

The central exponential-route/linear-storage claim appears directly in
[Deep Mixtures of Experts](https://arxiv.org/abs/1312.4314), which stacks
separately gated expert sets to obtain exponentially many effective expert
combinations with modest model size.  Modern work also factorizes expert
weights through shared latent spaces, including
[Mixture of Latent Experts](https://arxiv.org/abs/2503.23100), and composes
specialized language-model modules, including
[Self-MoE](https://arxiv.org/abs/2406.12034).

The algebra is therefore a useful baseline, not an undiscovered scaling axis.

## Retained question

One narrower opportunity remains: use typed, noncommuting primitive banks with
an explicit source-family theorem showing that natural instruction factors are
recoverable and that unseen combinations are required by the held-out task.
That would test compositional acquisition rather than rediscovering the route
count.  It currently repeats the project's unresolved semantic-routing problem
and is not admitted to implementation.
