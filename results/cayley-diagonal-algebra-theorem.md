# Cayley-diagonal operator algebra — universality and hard lower bound

Status: **proved algebraic boundary; capability remains empirical**  
Date: 2026-07-30

## Result in one sentence

Two generically oriented diagonal operator families generate the full matrix
algebra under composition, but representing an arbitrary dense matrix still
requires at least `D` learned diagonal stages; short program paths can only win
when useful transformations share compositional structure.

## 1. One basis is not enough

Fix an orthogonal matrix `Q` and let

\[
\mathcal A_Q=\{Q^T\operatorname{diag}(d)Q:d\in\mathbb R^D\}.
\]

Every pair of elements in `A_Q` commutes, and the family has dimension `D`.
Products remain in the same family.  Repeating one Cayley basis with different
diagonal payloads therefore never creates generic cross-coordinate matrix
algebra; in `z=Qx` coordinates it is only coordinate-wise computation.

This is why the program tree cycles independent bases.  More depth in one
basis cannot repair the obstruction.

## 2. Two generic bases generate every matrix direction

Let `D` denote the algebra of all diagonal matrices over the complex numbers,
and let `R` be a generic invertible change of basis.  Consider the unital
algebra generated by

\[
\mathcal D \quad\text{and}\quad R^{-1}\mathcal D R.
\]

Any subspace invariant under every matrix in `D` is a coordinate subspace: it
is spanned by a subset of the standard basis vectors.  Any subspace invariant
under every matrix in `R^-1 D R` is the inverse image under `R` of a coordinate
subspace.  For generic `R`, no nontrivial coordinate subspace equals such an
inverse image.  The joint action is therefore irreducible.

By Burnside's matrix-algebra theorem, an irreducible unital subalgebra of
`M_D(C)` is the full matrix algebra.  Consequently,

\[
\operatorname{alg}(\mathcal D,R^{-1}\mathcal D R)=M_D(\mathbb C)
\]

for generic `R`.  The same statement holds for the real construction after
complexification, outside a measure-zero set of exceptional relative bases.

Sparse skew generators with continuously sampled nonzero edge weights produce
dense Cayley responses generically.  Two independently sampled responses have
a generic relative basis except on an algebraic measure-zero set.  Thus two
sparse-Cayley-conjugated diagonal families can generate every matrix direction
through sums and products, despite each individual family having only `D`
degrees of freedom.

The executable Stage-0 witness is the finite case: at width eight, 64 path
Jacobians from three cyclic bases span all 64 dimensions of `M_8(R)`.

## 3. Why this does not make arbitrary dense maps cheap

Fix the bases and consider a length-`L` product whose learned state consists of
one `D`-vector per stage.  It is the image of a smooth map

\[
F:\mathbb R^{LD}\rightarrow\mathbb R^{D^2}.
\]

If `LD < D^2`, the differential of `F` has rank at most `LD` everywhere.  Its
image cannot contain an open subset of matrix space.  Therefore a family that
can represent an arbitrary dense matrix needs

\[
\boxed{L\ge D}
\]

learned diagonal stages in the worst case.  With `Theta(D)` work per stage,
the worst-case application cost returns to `Theta(D^2)`.  This is the exact
degrees-of-freedom wall; full rank of each factor does not evade it.

## 4. The conditional opening

The program tree does not claim that one short path represents an arbitrary
dense matrix.  It spends `Theta(D^2)` resident bytes across many node payloads,
then activates a path of only `Theta(log D)` nodes.  The possible path maps are
numerous but correlated through shared prefixes and bases.

The node-to-route-coordinate map is an implicit integer hash.  No hidden
`O(number of nodes)` index table is omitted from the resident-byte claim.

That creates a real alternative scaling currency:

- ordinary dense layer: one largely arbitrary transform, `Theta(D^2)` active
  weights and arithmetic;
- dense MoE: many arbitrary transforms, `Theta(D^2)` active weights per chosen
  expert and more resident bytes;
- vector memory/PEER: `Theta(D)` per active expert, but rank-one local updates;
- Cayley-diagonal path: full-rank local updates, `Theta(D log D)` active
  payload/work, `Theta(D^2)` total resident payload, and correlated
  compositional transforms.

The only remaining question is empirical and sharp: do language computations
have enough reusable basis-and-path structure for those correlations to be an
advantage rather than a restriction?  No algebraic rank, route-count, or
synthetic self-generator result can answer it; the matched language and
hardware gates are mandatory.
