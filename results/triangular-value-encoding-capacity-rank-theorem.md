# TVE capacity-rank theorem

## Claim

Triangular value encoding (TVE) does not merely choose a different optimizer
coordinate system. At a generic canonical value/output factorization, it turns
former gauge-orbit directions that are exactly function-null in ordinary
attention into linearly independent nonlinear function directions.

For a value head of width `d`, the full-head construction can recover
`d(d-1)/2` such directions without adding a parameter. A block size `B` recovers

```text
(d / B) B(B - 1)/2 = d(B - 1)/2
```

directions for one value head. Thus `d=64, B=16` recovers 480 directions and
`B=64` recovers all 2,016 orthogonal-gauge directions. Summing this count across
GQA KV heads requires the generic-rank conditions stated below.

This is a local function-rank result. It does not by itself establish better
language-model loss, useful scaling, or zero latency overhead; those remain
experimental gates.

## One-token reduction

Use column-vector convention and consider one token and one attention head.
Softmax is exactly one, so ordinary attention reduces to

```text
f(V, O; x) = O V x.
```

Let `G(t) = exp(tA)`, where `A` is skew-symmetric. The orthogonal value/output
gauge path is

```text
V(t) = G(t) V0,
O(t) = O0 G(t)^-1.
```

Therefore

```text
O(t) V(t) = O0 V0
```

for every `t`. All `d(d-1)/2` tangent directions generated by `A` are exactly
null directions of the ordinary attention function.

Choose the canonical representative `O0 = R`, with `R` upper triangular and a
nonzero diagonal. TVE reads the strict-lower physical coordinates of `O(t)` as

```text
C(t) = lower(O(t)) / tau
```

and applies

```text
F_C(z) = z + C phi(z),
phi(z)_j = z_j |z_j|.
```

The TVE attention function along the same former gauge path is

```text
f_TVE(t, x) = O(t) F_C(t)(V(t)x).
```

At the canonical point `t=0`, `C(0)=0`. Differentiating gives

```text
d f_TVE / dt |0
  = d[O(t)V(t)x] / dt |0
    + O0 C'(0) phi(V0 x)
  = O0 C'(0) phi(V0 x).
```

The entire ordinary linear term cancels because it is a gauge orbit. The
former null direction now produces a nonlinear, piecewise-quadratic function.

## Why all gauge directions are recovered

Because

```text
O'(0) = -R A,
C'(0) = -lower(R A) / tau,
```

we need the linear map

```text
A (skew-symmetric) -> lower(R A)
```

to be nonsingular. For `i > j`,

```text
(R A)_ij = R_ii A_ij + sum_{k > i} R_ik A_kj.
```

Order the strict-lower pairs by decreasing `i`. This system is triangular in
the independent entries `A_ij`, with diagonal coefficients `R_ii`. A generic
RQ factor has `R_ii != 0`, so the map is invertible. Hence every one of the
`d(d-1)/2` orthogonal-gauge directions maps to a distinct strict-lower
coefficient direction.

For block TVE, restrict `A` to block-diagonal skew-symmetric matrices. The same
argument applies independently inside each block and yields `d(B-1)/2`
directions.

## Why these are new function directions

At one token, every ordinary-attention parameter derivative is linear in `x`,
because `f(V,O;x) = OVx`. The TVE gauge derivatives are combinations of

```text
O0 e_i phi((V0 x)_j),  i > j,
```

which are piecewise quadratic in `x`. With nonsingular `O0` and `V0`, these
functions are linearly independent for distinct `(i,j)` and cannot lie in the
ordinary attention tangent space.

Consequently, ordinary attention's parameter-to-function Jacobian loses at
least the gauge dimension, while TVE restores those directions as functional
rank. TVE contains the ordinary function family on the canonical `C=0` slice
and departs from it in nonlinear directions without increasing the physical
parameter count.

## Multi-token and GQA extension

The one-token case is a restriction of causal attention, so strict separation
there is sufficient to separate the attention-module function families.
Multiple tokens add attention mixing but do not remove the token-local TVE
term.

For fixed attention weights `a_ts`, TVE exposes a signed-second-moment-like
statistic before token pooling:

```text
sum_s a_ts phi(v_s).
```

In general this cannot be reconstructed from
`phi(sum_s a_ts v_s)`. An ordinary model can arrange related nonlinear value
features in an earlier layer or MLP, but that spends depth or other feature
capacity; TVE supplies a fresh lift immediately before every attention pool.
This is the proposed practical mechanism, not an additional separation proof
for a complete multi-layer Transformer.

For GQA, apply one gauge transform per KV head and its associated query-head
output columns. In the one-token reduction, sibling query heads sharing a KV
head receive the same value and their output maps sum. Therefore a nonsingular
representative sub-block alone is not sufficient: the aggregate output map for
the group must have full column rank, and the resulting ridge-function families
from different KV groups must be independent. Both conditions hold for generic
weights but can fail through exact cancellation or projection degeneracy. The
one-head theorem is unconditional under the stated nonsingularity assumptions;
the per-KV-head GQA count is a generic-rank extension, not a proof for every
possible GQA parameter point.

## What this proves and does not prove

Proved under exact-real, generic-rank assumptions:

1. The ordinary V/O factorization has exact function-null parameter directions.
2. For one head, full-head TVE converts all orthogonal null directions into
   independent nonlinear local function directions.
3. Block TVE converts the stated subset; the summed per-KV-head count for GQA
   additionally requires the generic aggregate-rank and cross-group
   independence conditions above.
4. The ordinary attention family remains available at `C=0` after gauge fixing.

Not proved:

1. A fixed-depth complete transformer cannot approximate these functions by
   reallocating its MLP or other layers.
2. Optimizers will discover useful members of the enlarged local family.
3. More recovered directions monotonically improve loss.
4. The fused serving implementation has literally zero latency cost.
5. BF16 preserves exact invertibility or exact-real rank at every input.

The experiments therefore test usefulness, optimization, numerical stability,
and native latency. They are not substitutes for this capacity argument; this
argument is not a substitute for those experiments.

## Numerical witness

`experiments/triangular_value_encoding_capacity_rank_witness.py` checks the
orientation and rank argument on generic FP64 systems. The first frozen run
produced:

| width | gauge directions | rank of `A -> lower(RA)` | sampled nonlinear function rank | ordinary gauge residual | TVE derivative relative error |
|---:|---:|---:|---:|---:|---:|
| 4 | 6 | 6 | 6 | `1.78e-15` | `6.76e-7` |
| 8 | 28 | 28 | 28 | `7.55e-15` | `5.27e-7` |
| 16 | 120 | 120 | 120 | `2.35e-14` | `5.14e-7` |

The witness is not statistical evidence and is not needed by the proof. It is
an executable guard against a transposition or strict-triangle mistake.
